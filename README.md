# AICG3D-QwenImage21

**Qwen-Image 2.1 的 ComfyUI 推理加速节点**（输出预测策略，官方描述提速 30~40%） · 完全免费 · 开源

> ⚠️ 本仓库是**第三方修改版，非官方版本**，与原加速版作者、Qwen 团队均无隶属或背书关系。

## 功能

- 对 Qwen-Image 2.1 推理做输出预测加速：`reuse_threshold`（默认 `0.06`，越大越快、画质损失越多）
- 单节点接入，串在原有 Qwen-Image 工作流里即可

## 安装

```
cd ComfyUI/custom_nodes
git clone https://github.com/JGRFW/comfyui-AICG3D-QwenImage21.git
```

## 节点

分类：**`AICG3D/Qwen Image 2.1`**

| 显示名 | 节点 ID |
|---|---|
| AICG3D Qwen Image 2.1 | `AICG3D_QwenImage21` |

## 本版改动（相对原加速版）

- 节点 ID、菜单分类、显示名统一到 AICG3D 命名空间（底层 `.pyd` 等长替换，文件大小不变）
- 新增 README / LICENSE(Apache-2.0) / THIRD_PARTY_NOTICES / pyproject.toml
- ⚠️ 从改名前的版本升级：节点 ID 变了，旧工作流里的节点会显示为 missing node，需重新拖入
